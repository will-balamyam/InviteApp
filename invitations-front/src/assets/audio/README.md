# Archivos de audio para invitaciones

## Instrucciones para agregar música de fondo

Para que la funcionalidad de música de fondo funcione correctamente, debes agregar los siguientes archivos en esta carpeta:

1. **background-music.mp3** - Archivo de música en formato MP3
2. **background-music.ogg** - Archivo de música en formato OGG (para mejor compatibilidad)

### Recomendaciones para los archivos de audio:

- **Duración**: Entre 2-4 minutos (se reproducirá en bucle)
- **Volumen**: Moderado, ya que se establecerá al 30% en el código
- **Género**: Música suave, instrumental o religiosa apropiada para bautizos
- **Calidad**: Buena calidad pero no excesivamente pesada (128-192 kbps)

### Ejemplo de música apropiada:
- Canciones instrumentales suaves
- Música clásica ligera
- Melodías religiosas apropiadas
- Música ambiental relajante

Una vez que agregues los archivos, la música se reproducirá automáticamente (sujeto a las políticas del navegador) o cuando el usuario interactúe con la página por primera vez.

### Control de música:
- Los usuarios pueden controlar la música usando el botón flotante en la esquina superior derecha
- El botón muestra 🎵 cuando está reproduciéndose y 🔇 cuando está silenciado
- La música se pausa/reproduce al hacer clic en el botón
